# Facebook and Instagram insights

The organization analytics report reads the selected Facebook Page and Instagram professional account live. Dashboard `/api/dashboard/analytics`, `get_organization_analytics`, and the Insights page use the same report. Better Auth owns linked accounts, tokens, renewal, and granted Instagram scopes; organization integrations name only the selected targets. Provider insight responses are not stored. A disconnect stops further reads.

## Current API contract

The implementation uses the repository's Facebook Graph `v25.0` and Instagram Graph `v23.0` adapters. Qualify those pinned versions before an API-version change. The [Meta Instagram insights guide](https://developers.facebook.com/documentation/instagram-platform/insights) requires `instagram_business_basic` and `instagram_business_manage_insights` for Instagram Login on `graph.instagram.com`; it does not use the Facebook Login scope family. The [Instagram account reference](https://developers.facebook.com/documentation/instagram-platform/api-reference/instagram-user/insights) documents `total_value`, daily period, `since`/`until`, and up to 90 days of account data. The [Instagram media reference](https://developers.facebook.com/documentation/instagram-platform/reference/instagram-media/insights) documents lifetime counts and type eligibility. The [Facebook Page Insights reference](https://developers.facebook.com/docs/graph-api/reference/insights/) requires `read_insights`, `pages_read_engagement`, a Page token, and the Page `ANALYZE` task; the selected account still supplies its Page token through Better Auth.

| Source | Metrics read | Meaning and period |
| --- | --- | --- |
| Facebook Page | `page_media_view`, `page_post_engagements` | Daily values summed across the selected date range. Media views include displays or plays of posts, stories, videos and ads; engagements include Page post reactions, comments and shares. |
| Facebook Page | `page_total_media_view_unique`, `page_follows` | Latest available daily snapshot. Unique daily viewers and follower totals are never summed across days or networks. |
| Facebook post | `post_media_view`, `post_total_media_view_unique`, reaction counts by type | Lifetime values on posts published within the selected date range; post viewers are unique only for that post. |
| Instagram account | `views`, `reach`, `accounts_engaged`, `total_interactions`, `profile_links_taps`, likes, comments, shares, saves | Provider `total_value` for the selected period. `reach` and `accounts_engaged` are distinct estimated account counts; no cross-platform deduplication is implied. |
| Instagram account | `follows_and_unfollows` with `follow_type` breakdown | Follows and unfollows in the selected period, where Meta returns the breakdown. Accounts under 100 followers can have this metric withheld. |
| Instagram media | views, reach, interactions, likes, comments, saves, shares, plus profile activity and visits on feed posts | Lifetime values on media published within the selected date range. Carousel children are not queried because Meta reports insights on the parent. Instagram Login metrics exclude activity on promoted copies or other surfaces. |

Each report also reads the preceding equal-length period when that period is within provider retention. A missing, unsupported, threshold-limited, denied, or failed metric carries a null value and a reason; zero is used only when Meta returned numeric zero. Instagram account insights may be delayed 48 hours, and Meta returns an empty data set for unavailable values. Facebook Page insights require a Page with at least 100 likes and may update daily. Older Instagram `impressions` and Facebook Page/post impression or reach metrics were retired; do not substitute them for current views or add daily unique counts to construct an audience.

Native content uses provider cursor pagination, twelve posts per page. The dashboard offers Load more, and the MCP/API return `nextCursor` for each provider. The view ranks posts by media views among those loaded; inspect every page to cover the whole date range, and inspect metric statuses before treating the order as a complete ranking. Content metrics are lifetime values, while the selected range filters **publication dates**. A lost scope, changed connection revision, provider rejection, or unreadable page is reported to the caller; none produces fabricated zeros.

## Meta review and runtime evidence

The Facebook Login for Business configuration ID carries scopes and cannot take a scope list in the Better Auth request. Add `read_insights` to that Meta configuration and the review manifest alongside the existing Page permissions. Instagram Login requests `instagram_business_manage_insights` through Better Auth; an existing linked account must reconnect and grant it. Neither a code scope list nor an OAuth-only recording proves review access.

For an owner-authorized Page and Instagram account, record successful native API calls for each permission; compare the exact provider metric, value, period, target ID and date range with the authenticated dashboard response and the MCP result.
